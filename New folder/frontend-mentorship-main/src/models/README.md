# Models

This folder contains TypeScript type definitions, interfaces, and enums used across the application.

## Conventions

- Group related types into files (e.g., `user.ts`, `api.ts`).
- Export interfaces, types, and enums — avoid concrete values.
- Name files after the domain concept they describe.
- Import these types in `src/api/`, `src/components/`, and `src/pages/` as needed.
